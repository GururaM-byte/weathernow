
# WeatherNow – Weather Forecast Application

A responsive weather forecasting web application built using Angular and Django.

##  Live Demo

**Website:** https://weathernow-gamma-ten.vercel.app/

##  Project Overview

WeatherNow allows users to search for any city and view its current weather conditions and 5-day weather forecast.

##  Features

- Search weather by city name
- View current temperature
- Weather condition and description
- Humidity and wind speed details
- 5-day weather forecast
- Responsive user interface
- Live API integration

##  Technologies Used

**Frontend:** Angular, TypeScript, HTML, CSS

**Backend:** Python, Django

**API:** OpenWeatherMap API

**Deployment:** Vercel and Render

##  Deployment

- Frontend hosted on Vercel
- Backend hosted on Render

##  Developer

Developed as a web development project to demonstrate frontend, backend, API integration, and deployment skills.
